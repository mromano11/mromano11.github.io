# Getting the Message — dissertation companion website

Static, accessible, responsive HTML/CSS/JavaScript website. No build tools or paid services required.

## Publish on GitHub Pages
1. Create a new **public** GitHub repository (e.g. `getting-the-message`).
2. Upload the **contents** of this folder to the repository root (keep `assets/` intact).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, `main`, `/ (root)`, then save.
5. GitHub will provide a site URL after deployment.

## Before public release
- Check dissertation title, degree/committee metadata, chapter wording, and final quantitative findings against the defended manuscript.
- Confirm final publication metadata and add authorized publisher/DOI links to the papers page.
- Do not publish participant transcripts or individual responses without appropriate consent/IRB review.
- Review permissions before distributing a full dissertation PDF or journal PDFs.

`index.html` home; `chapters.html` index; `chapter-1.html` ... `chapter-8.html` chapter pages; `papers.html`, `findings.html`, `glossary.html`, `future.html`, `about.html`; `assets/style.css` and `assets/site.js`.
